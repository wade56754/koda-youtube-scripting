# 按题材选结构、排情绪、找范本

> 用法（硬流程）：写稿前 ① 用第一节判断题材 → ② 从自备语料库找 1 篇同题材原稿完整通读当活范本 → ③ 再动笔。
> **这是方法论参考，不是填空模板。** 各题材要点是写完后的对照清单，禁止照着格子写稿。范本与本文冲突时，以范本为准——范本是活的，表格是死的。
> 依据：罗辑思维 1261 期逐字稿按题材抽样研究。范本期数见文末。

## 一、怎么选题材（先问观众脑子里已有什么旧故事）

| 观众脑子里已有的东西 | 题材 | 主结构 | 这篇要的情绪结果 |
|--------------------|------|--------|----------------|
| 一张很硬的人物脸谱 | 人物翻案 | 剥洋葱 / 二次翻转 | 恍然大悟 |
| 一堆碎片，说不清怎么回事 | 谜案 | 侦探拼图 | 悬疑解开 |
| 一句人人都觉得对的话 | 反常识 | 小模型 + 阶梯多故事 | 被冒犯后觉得有道理 |
| 一件正在发火的社会痛 | 社会隐痛 | 降温声明 + 倒回起源 | 火被降下来，机制听得进去 |
| "那是新闻，跟我无关" | 趋势 / 命运 | 利益绑定 + 现场 | 被点到，冷静做选择 |
| 一句正确的空话（要努力、要有战略） | 方法 / 概念 | 方法骑在一个人身上 | 多了一个能用的词 |
| "这东西太土，不配当主角" | 土物件 / 创新 | 先贬后问 | 土东西翻成大问题 |
| 一段课文已经写死 | 课本事件 | 先演旧版本再切镜头 | 官方版本裂开 |
| **个人亲历复盘（本清单之外）** | 个人叙事 | `story-framework.md` 十一条框架 | 跟着走完一段真实变化 |

个人叙事类是边界：研究对象几乎不讲自己的故事，所以八题材里没有这类。这类稿主骨架走非虚构故事框架，本文只借情绪总轨道和旋钮表。

## 二、情绪总轨道（所有长稿的底盘）

```
0. 坐下      轻、熟、有点好笑
1. 点头      稳，"我懂这个"
2. 第一掌    咦，被掀翻
3. 投入      跟着走，几乎又信了
4. 再掌      更深的愣，不要更吵
5. 结构层    冷、清楚，不煽情
6. 落到你    被点到；口气变轻；一句能带走
```

温度：**暖 → 稳 → 掀 → 沉 → 清 → 轻收。**

- 开场不哭，高潮不吼，结尾不喊加油。最重的判断落在结构层
- 每一段一种主情绪。**连续三段不要同温度**（冷段连排两段是常态，不必段段硬换）
- 真答案那一层必须更冷；结尾那句必须比倒数第二段更轻

## 三、调温旋钮

| 旋钮 | 放哪 | 干什么 |
|------|------|--------|
| 自嘲 | 开场、重段之后 | 让人坐下、透气。只嘲状态/生意/体型，不嘲判断 |
| 段子 | 长史实、沉重、复杂推演之后 | 笑完一句拽回主题，段子不孤立 |
| 预判骂声 | 论点最刺人的位置 | 替观众把火说出来，泄压后再论证 |
| 反问 | 每几句换气 | 往下推，不是"难道你不感动吗" |
| 借别人的嘴 | 最重的判断 | 自己少吼 |
| 金句 | 段末或篇末 | 前一句是故事最后一个动作 |

不用的情绪：开场哭、开场喊、开场正确；全程义愤；纯惨或纯神；"我们一起加油"；在结构真相上煽情。

## 四、各题材对照要点（写完后核对，不是写作模板）

- **人物翻案**：入场承认自己也信过旧脸谱（暖）→ 逐层立靶讲故事击碎（每层新问题过渡）→ 真答案落结构层（冷、短句砸）→ 升维落到观众（轻金句）
- **谜案**：抛"不该发生的结果"（蹊跷）→ 排除假解释（像划掉嫌疑人）→ 声明新视角 → 按时间复盘已知事实、留扣 → 拼出新主线解扣（"对上了"）→ 冷揭底
- **反常识**：先接住观众的不服（轻挑衅）→ 生活小模型（能看见的）→ 自己拆台泄火（"这话听着像诡辩"）→ 历史/数据/极端现场验证 → 换领域再验 → 硬金句或收在怀疑
- **社会隐痛**：先降温声明（只解释机制，不站队不解决）→ 一个具体的疼点，只扎一下 → 拉远回起源 → 讲机制 → 不给方案，留人自己掂量
- **趋势/命运**：先绑到观众利益 → 把反方悲观说圆（禁嘲讽）→ 声明"这是机制判断不是预言" → 现场故事 + 贯穿比喻 → 推演到具体职业/家庭 → 冷收，给选择不给打气
- **方法/概念**：旧空话 → 拿对不上的现实砸 → 抓手人物反复做同一类事 → 给方法起短名字（情绪高峰）→ 跨行验证 ≥2 → 可复述的心法收口
- **土物件**：先贬（"就这？"）→ 挂一个比物件大的问题 → 按时间讲完正片 → 回答大问题，落差就是爽
- **课本事件**：把通行版本完整演一遍（熟）→ 切另一台摄像机（咦）→ 对照与机制（冷，禁把另一面写成新脸谱）→ 轻硬收

## 五、短稿压缩（8 分钟 / 约 2000 字）

不论哪种题材，压成四步。砍的是层数和故事数量，动作一个不能缺：

```
【0】固定坐下句。平。
【1】大家的第一反应：____。熟。
【2】一本书 / 一个人换角度：____。咦，不大吼。
【3】连打 2-3 个具体误解（误解 → 其实）。小爽，连续的。
【4】一句糙理 + 走人。轻。不升华。
```

8 分钟里不要走"暖到冷再到轻"的大弧，走不完会假。

## 六、写完四问

1. 前 300 字有没有让人先点头，再被掀一下？
2. 有没有一个能看见的人（有名有姓，还有最后一句）？故事卡里出现"某人""人们""很多人"，作废重写
3. 有没有第二层？有没有连续三段同温度？
4. 结尾那句能不能单独转发？是不是比倒数第二段更轻？
