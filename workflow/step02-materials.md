# Step 02 · 事实与材料

> 目的：为选题备齐真实事实与素材。写作只许用这里登记过的材料——材料包之外的事实不许进稿。

## 执行

1. **创作者素材盘点**：亲历故事、原话、真实数据、截图。列清单，逐条标注「可直接进稿」/「需补细节」。本人原话逐字保留，不改写
2. **内部挖掘**：grep 创作者的历史内容（文章 / 视频转录 / 推文档案），找本人写过的同题判断和故事
3. **外部调研**：关键事实与数据交叉核实，记来源和日期；对标 1-2 条同题爆款记结构（只参考不复制）
4. **数字溯源表**：每个将进稿的具体数字一行——数字 / 来源 / 风险 / 处理。无来源的数字：模糊化或显式标注为修辞，否则不进稿
5. **缺口清单**：故事线可能需要但还缺的素材（尤其 Scene 级细节：时间地点 / 看见什么 / 当时反应），列出来向创作者要

## 产出

`step02-materials/materials.md`（素材清单 + 溯源表 + 缺口清单）
→ `step03-structure.md`
