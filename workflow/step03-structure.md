# Step 03 · 故事线设计（结构与包装）

> **输入优先级（第一铁律）**：创作者给定的因果链 = 最高输入件。有链 → 跳过论证设计，只做故事化施工。链缺素材回 step02 补；链有逻辑断点报创作者裁决，不擅自改。未给链 → 基于材料包提案因果链，创作者裁决后生效。
> 前置装载：
> ① `reference/standard-structure.md`——六块骨架 + 硬规则（观点型默认）
> ② `reference/story-framework.md`——非虚构故事框架（个人叙事型默认）
> ③ `reference/genre-emotion-map.md`——定题材、选范本、排情绪
> 输入：创作者的因果链 + step02 材料包。

## 执行

0. **定型**：判断观点型（讲判断，套六块骨架）还是叙事型（讲经历，走故事框架：五要素自检 + Scene/Summary 分配）。

1. **故事化施工（本步核心）**：给因果链上每个节点配齐四件——
   - **场景（Scene）**：关键转折点选 2-3 个细写（时间地点 / 在干嘛 / 看见什么 / 当时怎么想 / 做了什么选择），其余 Summary 压缩
   - **冲突**：每个节点"无法同时得到两样东西"的具体矛盾是什么
   - **情绪温度**：按情绪总轨道标每块温度（暖→稳→掀→沉→清→轻收）；连续三段不同温度；真答案层要冷，结尾要轻
   - **画面手法**：进入人物心理 / 戏剧化细节 / 假设亲历 / 跨域类比配独立故事，每块 ≥1 个

2. **先写 payoff**：定 2-3 个"观众拿走什么"，每个挂到因果链节点或材料包真数据上。没有真事真数的块，删块缩片。

3. **反转链自检**：链上每层做删层测试——删任一层片子必须断；答案深度浅→深排序，谜底放最后一层（谜底后置）。

4. **时间轴**：每 60-90 秒一个 Setup/Tension/Payoff 块 + 段尾钩；第一个 payoff 不晚于总片长 25%；个人史资格证明 ≤90 秒；先手拆最强质疑；结尾问题或预告，不总结。

5. **包装先行**：3 组标题 + 封面文案候选，面向 step01 定的观众。标题承诺 = 前 30 秒必须兑现。

6. **给创作者过目**：故事线表（节点×场景×冲突×情绪）+ 时间轴 + 3 组包装。认可后才进 step04。

## 退出条件

`step03-structure/structure.md`（故事线表 + 时间轴 + 情绪标注）+ 创作者选定的包装。
→ `step04-draft.md`

## 附录 · 判断挖掘问题库（仅创作者未给因果链且判断不明时使用）

用提问挖创作者本人的观察与判断，六个方向（问题必须结合选题具体化，禁止复读模板）：

| # | 方向 | 挖什么 |
|---|------|--------|
| 1 | 预期落差 | 动手前的预期 vs 实际结果，差得最远的一件事（反常识点最好的矿） |
| 2 | 共识错层 | 该话题的主流说法错在哪一层；见过的具体失败案例 |
| 3 | 反着来的决定 | 有没有故意跟主流反着做的决定，为什么敢 |
| 4 | 没人说透的现象 | 观察到但行业还没人讲透的东西 |
| 5 | 一句话 | 观众只能记住一句话，希望是哪句（用本人原话） |
| 6 | 最没底的事 | 真实的不确定——最值钱的信任素材 |

一次 ≤6 问；不问资料能查到的事实；回答有金子时追问，一次只追一层。
